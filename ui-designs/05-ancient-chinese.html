查阅完毕。当前存在三处将明文 token 写入 cookie 之处，且未设 httpOnly 与 secure 标记。重构策略如下：

  1. 引入 Redis 为 session 存储后端，token 以 AES-256 加密后存入服务端
  2. Cookie 仅保存不可逆 session ID，设置 httpOnly + secure + SameSite
  3. 增加 TTL 过期与滑动续期逻辑，默认一时辰自动失效
class RedisSessionStore: def create(self, user_id: str, token: str) -> str: sid = secrets.token_urlsafe(32) encrypted = self._encrypt(token) self.redis.setex(f"sess:{sid}", 3600, encrypted) return sid def validate(self, session_id: str) -> str | None: raw = self.redis.get(f"sess:{session_id}") if not raw: return None self.redis.expire(f"sess:{session_id}", 3600) return self._decrypt(raw)
