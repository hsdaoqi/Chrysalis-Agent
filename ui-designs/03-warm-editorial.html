分析完成。当前有 3 处直接在 cookie 写入明文 token，没有设 httpOnly 和 secure。重构方案：

  1. 引入 Redis 作为 session store，token 加密后存服务端
  2. Cookie 仅保存不可逆的 session ID，设置 httpOnly + secure + SameSite
  3. 增加 TTL 和自动续期逻辑
# session_store.py class RedisSessionStore: def create(self, user_id: str, token: str) -> str: sid = secrets.token_urlsafe(32) payload = self._encrypt(token) self.redis.setex(f"sess:{sid}", 3600, payload) return sid def get(self, session_id: str) -> str | None: raw = self.redis.get(f"sess:{session_id}") return self._decrypt(raw) if raw else None
