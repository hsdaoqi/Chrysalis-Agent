# Chrysalis Web SOP

## 当前定位

Chrysalis 现在只有一个轻量 `web_fetch(url)` 原子工具，用来读取网页 HTML 文本。GA 里的浏览器插件、CDP、跨标签页控制、文件上传、Cookie 操作暂时没有复刻进来。

## 适用场景

使用 `web_fetch`：
- 获取公开网页文本
- 读取文档页面
- 抽取简单 HTML 内容

不适合 `web_fetch`：
- 需要登录
- 需要点击、滚动、执行 JS
- 需要处理 HttpOnly Cookie
- 需要截图或视觉判断
- 需要验证复杂前端交互

## 使用规则

1. 先确认任务真的需要联网。
2. 只抓公开 URL，不抓密钥、后台管理页或私人数据。
3. 抓到 HTML 后，让模型基于观察结果继续决定下一步。
4. 如果页面依赖 JS 渲染，明确告诉用户当前 Web 能力不足，而不是伪造结果。

## 后续可复刻方向

等核心循环稳定后，再考虑按 GA 拆出：
- 浏览器会话工具
- 页面扫描工具
- JS 执行工具
- 截图验证工具

这些能力必须作为独立工具逐步加入，不能把 GA 的旧插件说明直接当成当前能力。
