# Chrysalis 记忆整理 SOP

## 目标

让 L1 保持“存在性索引”，让 L3 保持“短而有用”，避免项目再次变成一堆看不懂的历史沉积。

## L1 整理规则

保留：
- 文件名本身不能完全说明用途时的短触发词
- 真的会影响行为的红线规则
- 当前项目已经具备的能力入口

删除或下沉：
- 名字翻译
- 操作步骤
- 一次性任务结果
- 已被 SOP 覆盖的细节
- 当前项目还没有实现的 GA 能力入口

## L3 整理规则

每个 SOP 尽量满足：
- 开头说明适用场景
- 内容是检查清单，不是长教程
- 不引用 Chrysalis 当前没有的工具
- 不把 GA 的旧目录、旧命令、旧插件当成事实

## 整理步骤

1. 读 `memory/global_mem_insight.txt`。
2. 对每一条判断：它是入口、规则、细节，还是过期内容。
3. 入口保留，细节移到对应 SOP，过期内容删除。
4. 读被索引的 SOP，确认文件存在且内容仍适配当前项目。
5. 修改后运行测试，确保记忆改动没有误导代码路径。

## 红线

- 不覆盖整份 L1，除非用户明确要求重写。
- 不写入密钥、临时 PID、临时 URL、一次性绝对路径。
- 不把“未来可能会做”的能力写成“已经存在”的能力。
