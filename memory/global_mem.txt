# Chrysalis 全局事实

# 已验证环境事实
- code_run 执行 Python 时 cwd = D:\Project\Chrysalis（项目根），不是 workspace/。写入文件直接使用相对路径（如 `titles.txt`），不要加 `workspace/` 前缀（已验证：加前缀导致 FileNotFoundError）。
- 你要读各种sop文件都是以.md结尾的文件
- Windows 当前用户 `韩顺` 的真实桌面已重定向到 `D:\桌面`，不要默认写 `C:\Users\韩顺\Desktop`；已用注册表 `User Shell Folders` / `Shell Folders` 和 `Shell.Application Namespace(0)` 验证均为 `D:\桌面`。

# LLM 配置
- 多模型配置文件: configs/llm_models.json（JSON数组，按顺序加载）
- 配置加载逻辑: configs/config.py → load_session_configs() 读取 llm_models.json，支持 ${ENV_VAR} 展开
- provider字段决定协议: "anthropic"→Anthropic SDK(/v1/messages), "openai"→OpenAI SDK(/v1/chat/completions)
