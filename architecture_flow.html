10. 完整调用链总结
CLI/TUI 输入 → Kernel.run(task) → AgentLoop.run() → ContextEngine.assemble()
→ _run_function_calling() → LLMClient.chat() → BaseSession.ask()
→ trim_messages_history() → openai_stream()/claude_stream() → Response 解析
